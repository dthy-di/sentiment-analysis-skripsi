# Sentiment Analysis System

Aplikasi analisis sentimen menggunakan:
- AFINN Lexicon
- Multinomial Naive Bayes
- TF-IDF
- Tkinter GUI

## Features
- Load CSV / Excel / JSON
- Translate ID → EN (optional)
- AFINN labeling
- Naive Bayes training & prediction
- Export CSV result

## Technologies
- Python
- Scikit-learn
- Pandas
- Afinn
- Tkinter

## How to Run
pip install -r requirements.txt
python Skripsi.py
